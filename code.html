Software code

Free and open source under the GNU GPL v3. One HTML file, no build step.

Files

The whole app is one HTML file with a small offline worker, built on three.js and WebXR. No build step.

index.htmlThe app: start page, image library and everything in the headset (scanning, surface building, projection, panel, Resume)
about.html, guide.html, code.html, site.cssThese website pages and their shared style
sw.jsService worker: offline cache, network-first for app files
manifest.webmanifest, icons/Install as an app on the headset
docs/design.htmlSoftware design

Run it yourself

git clone https://github.com/sghosh37/trace-ar
cd trace-ar
python -m http.server 8000
adb reverse tcp:8000 tcp:8000   # headset on USB, then open http://localhost:8000

WebXR needs HTTPS or localhost, so serve it through adb reverse or any HTTPS host such as GitHub Pages.
